# GitHub Workflow Lab

Laboratório educativo em português para iniciantes praticarem branches, commits com mensagens claras, pull requests, conferência de diff e merge.

Este repositório é independente de outros projetos. O objetivo é aprender um fluxo de colaboração com melhorias pequenas, úteis e revisadas.

## Comece por aqui

Leia o [tutorial do primeiro pull request](docs/primeiro-pull-request.md) para praticar o fluxo completo, da branch ao merge.

## Princípios

- Faça uma alteração com propósito e escopo claro.
- Confira o diff antes do commit e antes do merge.
- Nunca publique credenciais, dados pessoais ou arquivos de outros projetos.
- Respeite as verificações e regras do repositório.

## Sobre Achievements

Esta atividade também permite observar o comportamento do Achievement Quickdraw. A concessão e o processamento dependem do GitHub; concluir o exercício não garante um selo.
